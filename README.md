# Projeto_14_chatbot_com_streamlit
#NEXUS_AI

Assistente virtual desenvolvido em Python utilizando **Streamlit** para a interface de utilizador e a API da **Groq** para processamento de linguagem natural. O projeto conta com um tema escuro customizado e persistência de dados local com SQLite.

---

## 🛠️ Tecnologias Utilizadas

* **Python** (Linguagem base)
* **Streamlit** (Interface gráfica web)
* **Groq API** (Modelo `openai/gpt-oss-120b`)
* **SQLite3** (Armazenamento de histórico de conversas)

---

## 🚀 Funcionalidades

* **Interface Moderna:** Tema dark intuitivo com estilo visual profissional.
* **Persistência de Histórico:** As mensagens do utilizador e do assistente são salvas automaticamente num banco de dados SQLite (`nexus_database.db`) e recarregadas ao abrir a aplicação.
* **Respostas Rápidas:** Integração com a API da Groq para respostas eficientes e diretas.
